## مقدمه

این سند رسمی و ساختاریافته است. نسخه ۲ با هدف **کمتر متن، بیشتر تصویر، هدر بزرگ‌تر** برای GitHub بازطراحی شده است.

> نسخه ۱: [amirhazbavi.github.io/shad](https://amirhazbavi.github.io/shad/)

## چکیده اجرایی

ابعاد موضوع به تفکیک بررسی شده و نتایج به صورت منظم ارائه شده‌اند. بخش قابل توجهی از متن ساختاریافته و تکرارشونده است.

## روش‌شناسی

رویکرد توصیفی-تحلیلی؛ داده‌ها از منابع معتبر؛ نمونه‌گیری سیستماتیک؛ اعتبارسنجی متقابل.

## تحلیل ساختاری

هر بخش مستقل قابل مطالعه است و انسجام کلی حفظ می‌شود. طراحی نسخه ۲ بر خوانایی و تصویرسازی تمرکز دارد.

## یافته‌ها

- متن سند طولانی است.
- طولانی بودن متن لزوماً به معنای عمیق بودن آن نیست.
- این نکته به طور رسمی تأیید یا رد نشده است.
- بند سوم فهرست قبلی بی‌معنا بود و حذف شد.

## جمع‌بندی

چارچوب ارائه‌شده منسجم و قابل استناد است. این سند یک تمرین سبک‌شناختی است؛ خواننده صبور یا کنجکاو یا هر دو، سپاسگزاریم.

## پیوست

جداول، نمودارها و منابع تکمیلی در این بخش ارائه شده‌اند.
